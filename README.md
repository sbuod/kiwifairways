# Kiwi Fairways

A searchable directory of New Zealand golf courses. Browse and filter courses by region, number of holes, and location. View green fees, membership costs, course difficulty ratings, and sort by distance from any location in New Zealand.

Live at [kiwifairways.co.nz](https://kiwifairways.co.nz)

## Tech Stack

- [Next.js](https://nextjs.org) (Pages Router)
- [Mantine](https://mantine.dev) UI components
- [Supabase](https://supabase.com) database
